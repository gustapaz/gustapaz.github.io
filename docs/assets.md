# Assets e origens

- Composição tipográfica, campo óptico WebGL, textura grain.svg, favicon, imagem social, capas genéricas e diagrama de transação: gerados por código original do projeto, MIT Gustavo Paz. O storyboard gerado para discussão não é asset do site.
- `public/media/vertice.webp`: prévia do projeto próprio [Vértice](https://github.com/gustapaz/vertice-studio/blob/main/docs/experience.png). Recorte superior e conversão WebP. Assets originais desse projeto mantêm seus créditos: [licenças](https://github.com/gustapaz/vertice-studio/blob/main/docs/assets-license.md).
- `public/media/tandem.webp`: prévia real do projeto próprio [Tandem](https://github.com/gustapaz/tandem/blob/main/docs/dashboard.png), recorte e conversão WebP. Fonte Inter da aplicação sob OFL.
- `public/media/confete.webp`: prévia real do projeto próprio [Confete](https://github.com/gustapaz/confete/blob/main/docs/public-gameplay.png), recorte superior e conversão WebP.
- Manrope / Mikhail Sharanda e Mirko Velimirovic; Space Grotesk / Florian Karsten. Distribuídas via Fontsource 5.3.0 sob SIL Open Font License. Texto completo do pacote conservado no export em `third-party.txt`.
- Conteúdo profissional: documentos fornecidos pelo proprietário. Publicada somente síntese profissional; PDFs originais, telefone, e-mail e endereço detalhado não são incluídos.
- Descrições de repositórios: metadados públicos de gustapaz, escapados e sujeitos a alterações. Não há download/execução de README ou conteúdo remoto no runtime.

- GSAP 3.15.1 e ScrollTrigger: GreenSock, licença padrão gratuita, inclusive para uso comercial. Avisos conservados em `third-party.txt`; não são cobertos pela licença MIT do código autoral. [Licença](https://gsap.com/standard-license/).

- `public/media/projects/`: capturas extraídas automaticamente dos próprios repositórios públicos de gustapaz, convertidas para WebP 1200/600 px sem ampliação. A origem exata de cada arquivo está em `public/data/previews.json`. As licenças e os créditos dos assets nos repositórios de origem continuam aplicáveis; as imagens não são declaradas globalmente como MIT. Não há serviço externo de screenshots ou execução de código desses projetos.
